## 🎯 Objetivo de la Tarea

### Descripción

Implementar una alternativa personalizada a Chatwoot para gestionar chats de WhatsApp vía Twilio, integrando agentes humanos y un agente IA.

### Alcance

- ✅ Incluido: Setup Monorepo, Next.js App, Firebase Integration, Twilio Webhook, AI Agent, Dashboard UI.
- ❌ Excluido: Despliegue a producción, Tests E2E completos, Gestión avanzada de usuarios (roles).

### Criterios de Aceptación

- [x] El webhook de Twilio recibe mensajes y los guarda en Firestore.
- [x] La IA responde automáticamente si no hay agente asignado.
- [x] Los agentes pueden ver y responder chats desde el dashboard.
- [x] El proyecto compila sin errores.

## 🏗️ Decisiones Técnicas

### Arquitectura Serverless

**Decisión:** Usar Next.js API Routes y Firebase.
**Justificación:** Permite escalar automáticamente y reduce costos de mantenimiento (sin servidores fijos).

### Integración Híbrida (Humano + IA)

**Decisión:** La IA solo responde si `assignedTo` es null o 'ai'.
**Justificación:** Evita que la IA interrumpa conversaciones que ya está manejando un humano.
